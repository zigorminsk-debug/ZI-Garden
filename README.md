# 🌱 ZI Garden — Календарь садовода

Карманный помощник садовода для **Беларуси и средней полосы**: календарь работ, справочники по посадке, болезням и вредителям, природный календарь фенологии, фото-дневник и урожай — всё в одном приложении, **работает без интернета**.

- Android 5.0+ (minSdk 21), собрано под Android 14 (targetSdk 34)
- Без рекламы, без аккаунтов, без аналитики
- Данные сада хранятся только на устройстве (экспорт — в CSV, по желанию — семейная синхронизация)

## Возможности

**Календарь и работы**
- 📅 Задачи на каждую неделю сезона с учётом ваших культур; выполненное уходит в архив
- 🌦 Прогноз погоды для вашего города рядом с задачами — выбрать правильный день проще
- ⏰ Напоминания только в разумные часы (8:00–21:00), дачный режим для приездов на участок
- 🧺 Четыре виджета рабочего стола: задачи, погода, сезонные угрозы, памятка дня

**Справочники**
- 🌿 46 культур — от яблони и картофеля до винограда и актинидии: сроки, почва, схема посадки (у каждой культуры — своя), соседи/антагонисты, уход
- 🛠 13 агроприёмов: обрезка (весенняя, осенняя, ягодных, молодых), пикировка, закаливание, черенкование зелёное и одревесневшее, отводки, деление куста, усы земляники, семена, прививка
- 🍂 233 карточки болезней и вредителей с фотографиями; отмеченные болезни включают кросс-сезонные напоминания о профилактике
- 🔬 12 дефицитов элементов — «читаем» растение по листьям и плодам
- 🌸 Фенология: 18 природных ориентиров сроков работ — от сокодвижения берёзы до черёмуховых холодов, с карточкой «Сейчас в природе»
- 552 иллюстрации; все подписи на схемах — на русском

**Ваш сад**
- 📸 Фото-дневник: снимки каждой культуры по этапам, история сезонов
- 🧺 Записи урожая по годам и культурам, журнал до 200 записей
- 📊 Экспорт журнала и урожая в CSV (дружелюбно к Excel)
- 👨‍👩‍👧 Семейная синхронизация между устройствами (по желанию)
- 🔎 Живой поиск сразу по всем справочникам
- 👋 Знакомство с приложением при первом запуске

**Масштаб:** 19 экранов · 15 плиток главного меню · 4 виджета рабочего стола · 552 иллюстрации · 394 автопроверки в CI.

## Установка и обновление

1. Скачайте APK из [Releases](https://github.com/zigorminsk-debug/ZI-Garden/releases) (последняя версия — вверху списка).
2. Разрешите установку из этого источника и откройте файл.
3. Дальше приложение обновляется само: «О программе» → «⬇️ Проверить обновления».

История изменений — в [CHANGELOG.md](CHANGELOG.md).

## Разрешения — и зачем они

Приложение запрашивает ровно то, что нужно, и ничего лишнего:

| Разрешение | Зачем |
|---|---|
| Интернет и состояние сети | прогноз погоды, обновления, синхронизация |
| Примерное/точное местоположение | определить город для погоды (по кнопке GPS) |
| Уведомления | напоминания о работах |
| Автозапуск | восстановить напоминания после перезагрузки телефона |
| Точный будильник | напоминания в срок |
| Установка пакетов | самообновление APK по вашей команде |
| Вибрация и блокировка сна | обратная связь и фоновые операции |

Фото для дневника добавляются через системный выборщик — **доступа ко всей галерее приложение не запрашивает**.

## Сборка из исходников

Проект собирается **без Gradle** — как в старой школе, но на современном SDK:

```bash
cd GardenCalendar
./build.sh          # aapt2 + javac + d8 + apksigner -> out/...apk
bash test.sh        # JVM-тесты логики (394 проверки), без эмулятора
```

Нужны: JDK 17+, Android SDK (platform 34, build-tools 34.0.0). Версия APK вычисляется из тега: `v2.73 → 2.73 / 93000`.

CI (GitHub Actions) на каждый коммит: тесты → сборка → подпись → артефакт; по тегу `vX.Y` — релиз и OTA-зеркало в `pages/`.

## Структура репозитория

```
GardenCalendar/   — приложение (src/, res/, img_src/, тесты логики, build.sh, test.sh)
sync-server/      — сервер семейной синхронизации (Python)
pages/            — OTA-зеркало обновлений (app.apk + latest.json)
.github/          — CI-воркфлоу
uploads/          — рабочие материалы разработки
```
