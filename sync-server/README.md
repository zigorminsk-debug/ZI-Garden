# ZI Garden — сервер семейной синхронизации

Крошечный сервер (один файл, **только стандартная библиотека Python 3** — без pip-зависимостей),
который даёт приложению ZI Garden семейные группы и общий сад:

- создание семьи: имя семьи + ваш логин + пароль;
- присоединение родных: то же имя семьи + свой логин + семейный пароль;
- синхронизация данных целиком по принципу «последнее новое состояние побеждает».

## API

| Метод | Путь | Тело | Ответ |
|---|---|---|---|
| GET | `/api/health` | — | `{"ok": true}` |
| POST | `/api/family/create` | `{"family","login","password"}` | `{"ok","family","login","token"}` |
| POST | `/api/family/join` | `{"family","login","password"}` | то же |
| POST | `/api/state/push` | `{"token","ts","json"}` | `{"ok","applied", "ts"}` |
| GET | `/api/state/pull?token=…` | — | `{"ok","ts","by","json"}` |

- Пароли хранятся как PBKDF2-HMAC-SHA256 (200 000 итераций, соль на участника).
- Токены случайные (24 байта), на сервере лежит только их SHA-256.
- Push применяется, только если клиентский `ts` **новее** серверного (иначе `applied:false` + чьё состояние новее) — старый телефон не затрёт свежее.
- Хранилище — файлы в `data/`, запись атомарная (temp + rename).

## Локальный запуск

```bash
python3 server.py --port 8080 --data ./data
# проверка
curl http://127.0.0.1:8080/api/health
python3 -m unittest test_server -v
```

## Постоянное развёртывание (бесплатно, ~10 минут)

1. Зарегистрируйтесь на бесплатном Python-хостинге: **Render**, **Railway**, **Fly.io** (любой).
2. Создайте **Web Service** из этого репозитория, каталог `sync-server/`.
3. Параметры: *start command* — `python3 server.py`, переменная окружения `PORT` выставляется
   хостингом автоматически (сервер её уважает). Билд-пакет — Python 3.11+.
4. Получите домен вида `https://<имя>.onrender.com`, впишите его в приложение:
   **Настройки → ☁️ Онлайн → поле «Адрес сервера»**.
5. Домен хостинга держит HTTPS «из коробки» — трафик семьи шифрован.

Альтернатива: домашний мини-ПК/Raspberry Pi или смартфон с **Termux**
(`pkg install python && python3 server.py --port 8080`) + проброс порта на роутере.

## Dockerfile

```dockerfile
FROM python:3.12-slim
WORKDIR /app
COPY server.py .
EXPOSE 8080
CMD ["python3", "server.py", "--port", "8080", "--data", "/data"]
```
